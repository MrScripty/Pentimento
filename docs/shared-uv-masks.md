# Basic grayscale UV layer masks

Each shared UV layer can have one optional atlas-sized grayscale mask. Add mask creates an enabled white mask. White reveals layer color, black hides it, and intermediate values reduce coverage. Disable preserves mask pixels and selects Color; Remove discards only the mask and selects Color. Both are recoverable through bounded UV Undo. Duplicate retains the mask, enabled state and selected paint target. New layers start without a mask.

## Painting and compositing

The selected layer exposes an explicit Color or Mask target. Mask requires an existing enabled mask. Layer and paint-target selection preserve Redo and create no history entry. Accepted edits restore their recorded layer/channel selection through Undo/Redo, consistent with existing layer history. Hidden, paint-locked or conflicted layers refuse painting either channel. Active strokes, pending Apply and live preview refuse layer/channel changes.

DirectUV Mask uses the existing brush, pressure, opacity and rasterizer. The brush panel exposes linear grayscale percent: 0% hides, 100% reveals. Colored brush presets are interpreted using linear brightness `0.2126R + 0.7152G + 0.0722B`; identical gray channels retain exact bits. Eraser reveals toward white. The existing RGBA work atlas encodes committed scalar coverage `m` as `[m,m,m,1]`. After erase, associated work pixels decode over white as `R + (1-alpha)`; opaque gray decodes directly. Untouched texels retain their original scalar float bits. A commit returns the workspace to canonical opaque gray.

Canvas Apply and live preview use the same selected channel. Mask projection uses the source canvas's premultiplied linear brightness with its existing alpha: `new_m = brightness(Ps) + (1-as)*baseline_m`. Transparent source pixels skip before brightness conversion, so latent transparent RGB cannot reveal or hide a mask. Canvas Eraser edits the source; preview recomputes from the committed mask baseline. Removing source paint restores baseline coverage in preview. Apply commits once and pauses live; Cancel retains Canvas edits and UV history. Receiver, layer and Color/Mask target remain pinned throughout the transaction.

One shared compositor multiplies all four associated layer color channels by enabled mask coverage, then applies layer opacity once, then the existing Normal/Multiply/Screen/Overlay operation. Disabled masks bypass coverage. Mask work/preview replacement changes coverage and never substitutes for raw layer color. The isolated UV-group/material boundary and existing display conversion remain unchanged. Masks do not modify geometry, mapping, guard tolerances or raw color data.

## History, ownership and files

Mask strokes retain only before/after scalar mask payloads at 4 bytes per sample plus metadata. Mask enable/disable records metadata without copying color or mask pixel payloads. Add/Remove and layer Duplicate/Delete retain the necessary scalar payloads independently of color changes. Accepted changed commits clear global UV Redo. No-op, rejected and cancelled strokes retain Redo. The existing global 64 MiB accounted history payload and 128-entry ceiling remain shared with legacy history and other receivers; eviction remains legacy first, then other receivers before the current receiver. This is not a process-memory bound.

Actual pending Mask baseline/preview buffers use RGBA and count 16 bytes per sample, subject to existing 32 MiB admission limits. Live source/mapping snapshots remain separately accounted. Working atlases, live document pixels, derived/original images, temporary composites, serialization and allocator overhead consume additional memory. Aggregate receiver and project sample admission conservatively counts color texels plus scalar mask samples. Limits refuse before authoring mutation; there is no unbounded mask-specific history.

Canonical project version remains v3. Optional mask data, enabled state and per-layer Color/Mask target persist; absent fields default to no mask, disabled and Color and are omitted for old-compatible unmasked layers. Any retained mask, including disabled masks, requires `linear-premultiplied-masked-separable-v1`. Older readers refuse unknown policy/fields instead of ignoring coverage. Unknown channels/policies, wrong lengths, nonfinite/out-of-range samples, enabled masks without pixels, and Mask targets without an enabled mask refuse detached validation before installation. Open creates fresh histories and reconstructs both channel workspace and color composite. Existing owned-file and external image/material/mesh conflict handling remains intact; UV history never rewinds foreign pixels or geometry.

## Qualification boundary

Core tests cover coverage/opacity with all four modes, exact untouched float bits, transparent projection, scalar history, lifecycle, defaults, validation and bounds. App tests use real command dispatch, native-window input forwarding and production Bevy CPU painting/projection/image paths: Color/Mask selection, real mask strokes/Erase/Cancel, Undo/Redo, blend/opacity/order, Apply/live, pending refusals, invalid Open, owned Save/Open followed by the first reopened mask stroke, external conflicts and shared history caps. Frontend checks build the product Svelte UI; compiled server-rendered tests cover acknowledged mask/channel controls, disabled states, DirectUV grayscale and Canvas source-color controls. IPC samples cover all mask operations.

Interactive browser controls for masks have not been qualified in this environment. The inherited browser harness launches with sandbox disabled, and this slice does not execute it under the user's sandbox constraint. Native desktop CEF embedding, GPU extraction/material shading and physical stylus remain blocked or unqualified. No runtime was downloaded and no sandbox setting was changed. All generated evidence/build outputs stay outside Git; any displayed screenshot must be JPEG85. Vector masks, per-mask transforms/opacity, invert/fill commands, extra blend modes, PTex masks and automatic receiver admission remain outside this basic slice.

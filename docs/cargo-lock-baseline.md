# Cargo lock baseline: reproducibility with known audit warnings

This application workspace commits its root `Cargo.lock` to keep its reviewed
resolution reproducible. Canonical launcher build/test/check/rustc commands and
standalone CI sculpting checks use `--locked`. Nested lockfiles remain ignored.
A lockfile is a source-resolution record, not a security or support certificate.
This baseline remains a draft with known audit warnings; it does not establish
merge readiness or runtime/GPU rendering qualification.

These are resolved graph paths, not proof that every vulnerable API executes in
every frontend or target. The inspected default rand0.7.3 graph lacks its `log`
feature, one required condition in that advisory, but this is not a blanket
exemption for all feature combinations. The historical Blitz development
snapshot has no demonstrated current maintenance commitment. Scanner coverage
does not establish absence of unknown vulnerabilities.

Maintenance work must separately evaluate the Dioxus SVG/font cohort, existing
GTK/Wry debt, and shared image/graphics dependencies. Do not force incompatible
versions, disable supported frontends or features, or add blanket audit ignores
to obtain a green result. An application lock can preserve known debt without
making it acceptable for release.

## Updating the baseline

CI verifies the committed root lock without regenerating it, records its hash
and metadata, and checks all focused commands with `--locked`. The audit checks
the reviewed lock hash explicitly and keeps the warning gate failing while these
findings remain. Its pinned scanner/database are a dated reproducible snapshot,
not an automatically current ongoing security service.

Dependency updates require a separate intentional generation step, complete
diff/source/typed-boundary review, refreshed audit evidence and reviewed audit
checksum update, then focused checks and the unchanged full canonical frontend
suite on the final commit. Do not update the audit checksum merely to bypass a
mismatch. Upstream library lockfiles are not substitutes for this workspace's
own resolution. Retain provenance when artifacts expire.
